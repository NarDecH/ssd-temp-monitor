คำถามที่พบบ่อย

ทำไมไอคอนขึ้น "--" (ไม่แสดงอุณหภูมิ)?

ไอคอน -- สีเทา = ไม่พบข้อมูลอุณหภูมิ สาเหตุที่พบบ่อย:

  1. แอปไม่ได้รันในสิทธิ์ Administrator — การอ่าน Get-StorageReliabilityCounter ต้องใช้สิทธิ์แอดมินเสมอ
  2. ไม่มี SSD ภายในเครื่อง (เช่น มีแต่ HDD)
  3. SSD รุ่นนั้นไม่รายงาน temperature counter ผ่าน WMI/CIM

เปิดเมนู tray → ดูรายละเอียด เพื่อดูดิสก์ทั้งหมดและเหตุผลว่าดิสก์ใดถูกนับหรือไม่

ทำไม USB card reader / external SSD ไม่ถูกนับ?

เป็นการตั้งใจออกแบบ — bridge chip ของอุปกรณ์ USB มักรายงานค่าอุณหภูมิที่ผิดพลาด (ค่ามั่ว, 0, 65535 หรือค่าว่าง) และที่วัดจริงพบว่าทำให้การอ่านค่าค้างถึง ~42 วินาทีต่อดิสก์ ซึ่งเป็นจุดบั๊กดั้งเดิมของโปรเจกต์นี้

แอปจึงกรอง BusType = USB ทิ้งก่อนอ่านค่าเสมอ — อ่านรายละเอียดงานวิจัยได้ใน RESEARCH.html

ต้องรันในสิทธิ์แอดมินตลอดหรือเปล่า?

ใช่ — ตัวติดตั้งตั้งให้ exe ขอสิทธิ์แอดมินเอง (UAC จะถามครั้งเดียวตอนเปิด) ถ้ารันจากซอร์สให้ใช้คอนโซลแบบแอดมิน ถ้าไม่มีสิทธิ์แอปจะยังทำงานแต่ไอคอนจะขึ้น -- เพราะอ่านอุณหภูมิไม่ได้

แอปอัปเดตเองได้จริงไหม แล้วถ้าเวอร์ชันใหม่พังล่ะ?

ได้ — แอปเช็ค GitHub release (stable หรือ pre-release ตาม Settings → Updates) ดาวน์โหลด + ตรวจ SHA-256 ก่อนติดตั้งทุกครั้ง

มี rollback อัตโนมัติ: เก็บ exe เวอร์ชันเก่าไว้ — ถ้าเวอร์ชันใหม่บูตไม่สำเร็จภายในเวลาที่กำหนด จะคืนเวอร์ชันเดิมพร้อมแจ้งผู้ใช้ และจดเวอร์ชันที่พังไว้เพื่อไม่เสนอซ้ำ

แอปถูกเปิดกลับมาเองเรื่อย ๆ คืออะไร? (watchdog) ปิดได้ไหม?

ตัวติดตั้งสร้าง scheduled task ชื่อ SSDTempMonitor Watchdog ที่รันทุก 1 นาที — ถ้าโปรเซสของแอปตาย (เช่น native crash) จะเปิดแอปกลับมาเอง เพื่อให้ไอคอนใน tray ไม่หายเงียบ ๆ

ลักษณะการทำงาน: รันแบบไม่มีหน้าต่างกระพริบ (ผ่าน wscript ไม่ใช่ powershell ตรง ๆ), เปิดแอปกลับในเซสชันของผู้ใช้ (ไอคอนขึ้นปกติ), ไม่เปิดสำเนาที่สอง (มี mutex กัน) ไม่แทรกช่วงที่ตัวอัปเดตอัตโนมัติ กำลังติดตั้งเวอร์ชันใหม่ และถ้าคุณกด Exit เองจากเมนู แอปจะจด marker ไว้ให้ watchdog รู้ว่าไม่ใช่ crash — จะไม่ถูกเปิดกลับจนกว่าคุณจะเปิดแอปเอง — ไฟล์ที่ใช้อยู่ในโฟลเดอร์ <ตำแหน่งติดตั้ง>\watchdog\ และ task จะถูกลบตอน uninstall

เปิด/ปิดได้จากในแอปเลย: เมนู tray → Watchdog กัน crash (ติ๊ก = เปิด) — ปิดแล้ว task ยังอยู่แต่ไม่ทำงาน เปิดกลับได้ทันที ในหน้า Settings → General ยังเลือกได้ว่าเมื่อกด Exit จะเขียน marker กัน watchdog หรือไม่ (ปล่อยไว้ = แอปอยู่ปิดตามที่คุณสั่ง) พร้อมช่องแสดงสถานะ task ปัจจุบัน

ทุกครั้งที่ watchdog ปลุกแอปกลับ (หรือข้ามงานเพราะ marker/ตัวอัปเดต) จะบันทึกเหตุการณ์ไว้ที่ %APPDATA%\SSDTempMonitor\watchdog.log — นาทีที่แอปรันปกติจะไม่มีบรรทัดใหม่ ถ้าอยากลองกลไกเอง รัน tools\e2e_watchdog_test.ps1 (คอนโซลแอดมิน) มันจะ kill แอป ให้ task ปลุกกลับ ทดสอบ marker แล้วเก็บกวาดเอง

ถ้าจะลบถาวร: 

schtasks /Delete /TN "SSDTempMonitor Watchdog" /F
สำหรับโหมด portable ให้รัน tools\install_watchdog.ps1 ครั้งเดียวจากคอนโซลแอดมิน

ใช้จาก USB stick ได้ไหม (โหมด portable)?

ได้ — โหลด portable.zip จากหน้า ดาวน์โหลด แตกซิปแล้วรันได้เลย ข้อมูลทั้งหมด (config / log / ประวัติ / สถิติสุขภาพ) เก็บในโฟลเดอร์ portable_data ข้าง ๆ exe — ยกไปเครื่องไหนก็ครบ ไม่เขียนทิ้งบนเครื่องที่เสียบ (ยกเว้น mutex ชั่วคราวขณะรัน)

อุณหภูมิเท่าไหร่ถึงปกติ / น่ากังวล?
เขียว≤ 50 °Cปกติ
ส้ม51–64 °Cอุ่น — ตรวจการระบายอากาศ
แดง≥ 65 °Cร้อน — แอปจะแจ้งเตือนเมื่อเกินเกณฑ์ต่อเนื่อง

SSD ทนถึง ~70 °C ได้แต่ควรลดให้ต่ำกว่า 65 เพื่ออายุการใช้งานยาวนาน

Wear / Read errors ในแท็บ Health แปลว่าอะไร?

Wear = อายุการใช้งานที่ใช้ไปของ NAND (100% = หมดอายุตามมาตรฐานผู้ผลิต): ≥ 75% เริ่มวางแผนเปลี่ยน, ≥ 90% ควรสำรองข้อมูลทันที Uncorrected read errors = ตัวนับข้อผิดพลาดการอ่านที่แก้ไม่สำเร็จ — ถ้าตัวเลขเพิ่มขึ้น ให้สำรองข้อมูลทันที แอปจะเตือนเองเมื่อเกิดกรณีเหล่านี้ และวิเคราะห์แนวโน้มได้ในรายงานรายสัปดาห์ (แท็บ Health)

ดาวน์โหลดแล้วจะรู้ได้อย่างไรว่าไฟล์ไม่ถูกดัดแปลง?

ทุก release มี SHA256SUMS.txt กำกับ — ตรวจด้วย certutil -hashfile ชื่อไฟล์ SHA256 แล้วเทียบกับ หน้าดาวน์โหลด (มีช่องวาง hash เทียบให้ทันที) ตัวอัปเดตอัตโนมัติของแอปก็ตรวจค่านี้ก่อนติดตั้งทุกครั้ง
