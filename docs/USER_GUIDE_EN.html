SSD Temperature Tray Monitor

Windows 10 / 11 Single-file Python app v1.12.0 Needs admin rights

A tiny app that shows your SSD temperature live on the Windows system tray icon (updated every second), with warning colors when a disk runs hot.

Features

🔢 Temperature in the icon
Hottest SSD, refreshed every 1 second — dark digits on green/orange, white on red, always readable
💺 Per-disk icons
One extra icon per NVMe/SATA SSD (optional)
🛡️ Automatic UAC
Elevates itself at launch — SMART reads need admin
📈 Live graph
Last 30 minutes, redrawn every second, min/max/avg
🔔 Overheat alert
≥ 65 °C sustained 30 s, cooldown 5 min — both configurable
⚙️ Settings window
Polling, alerts, history, icons, update channel
🌐 Bilingual UI
English / ไทย — tray submenu or Settings
👁️ Live preview
Two sizes, tabbed settings, theme presets
⬆️ Verified auto-update
Downloads from GitHub Releases, SHA-256 checked
🔌 Ignores USB readers
Internal SSDs only — no bogus readings, no 40 s stalls
🩹 Copy diagnostics
Full snapshot to the clipboard for bug reports
green ≤ 50 °C orange 51–64 °C red ≥ 65 °C

System requirements

  • Windows 10 / 11
  • Administrator rights (UAC) — temperature data comes from privileged SMART counters

Install

Option A — installer (recommended)
Download ssd_temp_monitor_setup_vX.Y.Z.exe from the releases page, run it, and optionally tick Start automatically at Windows login.
Option B — portable exe
Download ssd_temp_monitor_vX.Y.Z.exe and run it directly — no installation.
Option C — from source
pip install pystray Pillow, then double-click start_ssd_temp_monitor.bat (or run pyw ssd_temp_tray.py).

Auto-update

The app checks GitHub Releases on startup and every N minutes. A newer stable release raises one notification per release per session; install it via Check for updates.... Every download is SHA-256-verified against the release's SHA256SUMS.txt before it is executed, and a helper waits for the app to exit before the installer runs, then relaunches the app. Unattended usage:

ssd_temp_monitor.exe --update-now
Update channels: stable (default) never sees -rc1 tags; switch to pre-release in Settings to test release candidates early.

Event log

Startup/shutdown, overheat alerts and update attempts are written to %APPDATA%\SSDTempMonitor\ssd_temp_monitor.log (rotating, 512 kB × 3 files).

Run at startup (optional)

The installer can create the startup entry for you. Manual way: press Win+R, type shell:startup, and put a shortcut to the exe there.
