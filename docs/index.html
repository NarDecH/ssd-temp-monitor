SSD Temperature Monitor

แอป Windows ขนาดเล็กที่แสดงอุณหภูมิ SSDไว้บน system tray แบบเรียลไทม์ อัปเดตทุกวินาที พร้อมสีเตือนเมื่อดิสก์ร้อนเกิน และอัปเดตตัวเองอัตโนมัติจาก GitHub Releases

⬇️ ดาวน์โหลดเวอร์ชันล่าสุด 📦 ซอร์สโค้ดบน GitHub

Windows 10/11 · ต้องการสิทธิ์ Administrator (UAC) เพื่ออ่านอุณหภูมิ SMART

🔢 เรียลไทม์ทุกวินาที

ไอคอน tray โชว์อุณหภูมิของ SSD ที่ร้อนที่สุด (หรือแยกไอคอนต่อดิสก์) พร้อม tooltip รายดิสก์

🎨 สีเตือน 3 ระดับ

เขียว ≤ 50 °C · ส้ม 51–64 °C · แดง ≥ 65 °C พร้อม notification เมื่อร้อนจัดต่อเนื่อง

📈 กราฟย้อนหลัง 30 นาที

บันทึกประวัติ CSV แล้วดูกราฟสด พร้อมค่า min/max/avg แบบเรียลไทม์

🔌 กรอง USB อัตโนมัติ

ไม่นับ USB card reader/enclosure ที่รายงานค่าผิดและทำให้การอ่านค้าง (อ่านวิเคราะห์ใน RESEARCH)

🔄 อัปเดตตัวเอง

เช็ค GitHub Releases อัตโนมัติ ตรวจ SHA-256 ทุกไฟล์ก่อนติดตั้ง เลือกช่องทาง stable / pre-release ได้

🚦 ใช้ทรัพยากรน้อยมาก

ตัวเดียวจบ ไม่มี background service หนัก ๆ — ไฟล์เดียว + PowerShell query ที่กรองจากต้นทาง
