SSD Temperature Monitor

เห็นอุณหภูมิ SSD ของคุณได้ทุกวินาที โดยไม่ต้องเปิดโปรแกรมอื่น — ตัวเลขอยู่บน tray icon เลย สีเปลี่ยนตามความร้อน: 36°C เย็น · 58°C เริ่มร้อน · 72°C อันตราย

ทำไมต้องมี

SSD ร้อนเกิน 65°C คือเรื่องเงียบ ๆ ที่ทำร้ายเครื่องคุณ

🔥

ความร้อนทำให้ SSD ช้าลง

Thermal throttling ลดความเร็วเขียนลงฮวบฮัวโดยที่คุณไม่รู้ตัว

📉

อายุการใช้งานสั้นลง

ความร้อนสูงต่อเนื่องเร่งการสึกของเซลล์แฟลชและคอนโทรลเลอร์

🕶️

เครื่องมือทั่วไปรกเกินไป

ต้องเปิดหน้าต่างเฝ้าดูทั้งวัน — ในเมื่อที่ต้องแค่ "เห็น" ตัวเลข

ทางออก: เอาอุณหภูมิไปไว้ใน tray แล้วให้โปรแกรมเป็นคนเฝ้าให้

ฟีเจอร์

เบา สงบ และครบเรื่องสุขภาพดิสก์

  • ตัวเลขอุณหภูมิบน tray icon — อัปเดตทุกไม่กี่วินาที สีเขียว/ส้ม/แดงตามเกณฑ์ · รองรับหลาย SSD
  • กราฟย้อนหลัง — รายละเอียดระดับวินาที + กราฟ 24 ชั่วโมงระดับนาที พร้อม zone bands และปุ่มส่งออก PNG/CSV
  • สถิติการใช้งาน 7 วัน — min/avg/max, % สึกหรอ, จำนวนการแจ้งเตือน + รายงานรายสัปดาห์อัตโนมัติ (HTML/CSV)
  • แจ้งเตือนอัจฉริยะ — อุณหภูมิเกินต่อเนื่อง, SMART ผิดปกติ (read errors, สึกหรอสูง, เทรนด์สึกเร็ว)
  • ธีมสว่าง/มืดตาม Windows · 4 ภาษา (EN/TH/JA/ZH) · ปรับขนาด/ฟอนต์/สีของไอคอนได้ละเอียด
  • อัปเดตอัตโนมัติพร้อม rollback — ตรวจ SHA-256 ทุกไฟล์ ถ้าเวอร์ชันใหม่มีปัญหา ย้อนกลับเองได้
หน้าตาเป็นอย่างไร

ทุกอย่างอยู่ห่าง ๆ คลิกเดียว

🖥️

Tray icon ตัวเลขเด้งสด

เห็นอุณหภูมิโดยไม่ต้องเปิดหน้าต่าง — คลิกซ้ายเพื่อดูรายละเอียดดิสก์

📈

กราฟ 2 มุมมอง

ย้อน 30 นาทีละเอียดระดับวินาที และ 24 ชั่วโมงระดับนาที เซฟ PNG/CSV ได้

เมนู tray: กราฟ · สถิติ · ดีเทลดิสก์ · รีเซ็ตสถิติ · ตั้งค่า · อัปเดต

เริ่มใช้ใน 3 ขั้น

ติดตั้งจบภายในหนึ่งนาที

ดาวน์โหลด installer จากหน้า Download — มี Portable zip ให้ด้วย ไม่ต้องติดตั้ง
ติดตั้งและอนุญาต UAC — โปรแกรมขึ้น tray ทันที อ่านอุณหภูมิผ่าน SMART ของ Windows เอง ไม่ต้องตั้งค่าอะไร
ลืมมันไปได้เลย — เฝ้าดิสก์ให้ตลอด เจอความร้อน/SMART ผิดปกติค่อยเด้ง toast มาหาคุณ
