SSD Temp Lite Python ไฟล์เดียว · Portable

โปรแกรมแยกตัวเล็ก (lite/ssd_temp_lite.py) ทำอย่างเดียว: โชว์อุณหภูมิ SSD เรียลไทม์บน system tray — ไม่มีกราฟ ไม่มีประวัติ ไม่มีไฟล์ตั้งค่า และมีแค่ไฟล์เดียว ทั้งรันจากซอร์สหรือ freeze เป็น exe ก็สะอาดเหมือนกัน

โชว์อะไรบ้าง
  • ตัวเลขอุณหภูมิ บน tray icon อัปเดตทุก 5 วินาที — เขียว ≤50°C · ส้ม 51–64°C · แดง ≥65°C (เกณฑ์เดียวกับแอปหลัก)
  • Tooltip รวมทุกดิสก์ · คลิกซ้าย = รายละเอียด · คลิกขวา = Details / Refresh / Exit
  • ใช้คำสั่ง PowerShell SMART ชุดเดียวกับแอปหลัก (Get-PhysicalDisk + Get-StorageReliabilityCounter)

วิธี build เป็น exe (CI ทำให้อัตโนมัติในทุก release)

คอมพิวเตอร์ที่มี Python + PyInstaller สั่งเองได้:

pip install pystray pillow pyinstaller
cd lite
python -m PyInstaller --noconfirm --clean --onefile --windowed --uac-admin \
    --name ssd_temp_lite --icon ../app_icon.ico ssd_temp_lite.py
# ได้ dist/ssd_temp_lite.exe — ไฟล์เดียว จบ

ธงสำคัญ: --onefile รวมทุกอย่างเป็น exe เดียว · --windowed ไม่โชว์หน้าต่าง console · --uac-admin ขึ้น UAC ขอสิทธิ์ admin เอง (SMART ต้องใช้)

รันจากซอร์ส

pip install pystray pillow
python lite/ssd_temp_lite.py      # เปิด shell แบบ admin เพื่อให้อ่าน SMART ได้

การใช้งาน

  • สำคัญ: การอ่าน SMART ต้องสิทธิ์ admin — คลิกขวาที่ exe → Run as administrator (ถ้าไม่มีสิทธิ์ไอคอนจะโชว์ --)
  • รันพร้อมแอปหลักได้ (mutex คนละตัวกัน) — เหมาะกับเครื่องสำรอง/เครื่องที่อยากได้แค่ตัวเลข
  • Portable จริง ๆ: ไม่เขียน config, ไม่สร้างไฟล์ข้อมูล, ปิดแล้วจบ

อธิบายคำสั่งสำคัญในโค้ด

คำสั่ง / APIทำอะไร
Get-PhysicalDiskWindows enum ดิสก์ physical ทั้งหมด — กรอง MediaType -eq 'SSD' และ BusType -ne 'USB' (USB bridge รายงานอุณหภูมิมั่ว) — query ชุดเดียวกับแอปหลัก
Get-StorageReliabilityCounterดึง SMART: Temperature / Wear — ต้อง admin จึงจะคืนค่าได้ (ไม่งั้น temp = None → ไอคอนโชว์ "--")
subprocess.run(...CREATE_NO_WINDOW)เรียก powershell แบบเงียบ ไม่มีหน้าต่างดำกระพริบ พร้อม timeout 30 วิกันค้าง
pystray.Icon / icon.run()จัดการ tray icon + message loop ของ Win32 ให้ทั้งหมด — เมนูคลิกขวาสร้างจาก pystray.Menu (Details / status / Refresh / Exit)
threading.Thread(poller)เธรดหลักของ tray (icon.run) แยกจากเธรด poll — ทุก 5 วิอ่านอุณหภูมิแล้วสลับ icon.icon/icon.title (pystray ส่งต่อให้ message loop เธรดให้เองอย่างปลอดภัย)
PIL ImageDraw / ImageFontวาดเม็ดสี + ตัวเลขอุณหภูมิตัวหนากลางไอคอน — ใช้ฟอนต์ Segoe UI Bold, ตัวเลข 3 หลักย่อขนาดอัตโนมัติ, โค้ดวาดเดียวกับแอปหลัก
MessageBoxWหน้าต่าง Details แบบ native (กันปัญหา tk crash ที่เคยเจอ) — โชว์หนึ่งบรรทัดต่อดิสก์
CreateMutexW + GetLastErrorกันเปิดซ้ำ: ถ้ามี instance อื่นถือ mutex ชื่อเดียวกันอยู่ → ERROR_ALREADY_EXISTS (183) → ออกทันที
