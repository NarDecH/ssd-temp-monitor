SSD Temp Lite Pascal · Typhon/Lazarus · ไฟล์เดียว

โปรแกรมแยกตัวเล็ก (lite/ssd_temp_lite.lpr) ทำอย่างเดียว: โชว์อุณหภูมิ SSD เรียลไทม์บน system tray — ไม่มีกราฟ ไม่มีฐานข้อมูล ไม่ต้องติดตั้ง Python คอมไพล์แล้วได้ exe เล็ก ๆ ไฟล์เดียว ยกไปรันที่ไหนก็ได้

โชว์อะไรบ้าง
  • ตัวเลขอุณหภูมิ บน tray icon อัปเดตทุก 5 วินาที — เขียว ≤50°C · ส้ม 51–64°C · แดง ≥65°C (เกณฑ์เดียวกับแอปหลัก)
  • Tooltip รวมทุกดิสก์ · คลิกซ้าย = รายละเอียด · คลิกขวา = Details / Refresh / Exit
  • ใช้คำสั่ง PowerShell SMART ชุดเดียวกับแอปหลัก (Get-PhysicalDisk + Get-StorageReliabilityCounter)

วิธี build (Typhon หรือ Lazarus)

วิธีที่ 1 — ผ่าน IDE: เปิด Typhon/Lazarus → Project → Open Project → เลือก lite/ssd_temp_lite.lpr → กด F9 (Run)

วิธีที่ 2 — คำสั่งเดียว (ต้องมี lazbuild ใน PATH):

lazbuild ssd_temp_lite.lpr        # คอมไพล์ -> ได้ ssd_temp_lite.exe ข้าง ๆ ไฟล์

หมายเหตุ: ไฟล์นี้ใช้แค่ units มาตรฐานของ FPC (Windows/ShellAPI/Process) — ไม่ต้องมี LCL package อื่น และไม่มี dependency ภายนอก

การใช้งาน

  • สำคัญ: การอ่าน SMART ต้องสิทธิ์ admin — คลิกขวาที่ exe → Run as administrator (ถ้าไม่มีสิทธิ์ไอคอนจะโชว์ --)
  • รันพร้อมแอปหลักได้ (mutex คนละตัวกัน) — เหมาะกับเครื่องสำรอง/เครื่องที่อยากได้แค่ตัวเลข
  • Portable จริง ๆ: ไม่เขียน config, ไม่สร้างไฟล์ข้อมูล, ปิดแล้วจบ

อธิบายคำสั่งสำคัญในโค้ด

คำสั่ง / APIทำอะไร
Get-PhysicalDiskWindows enum ดิสก์ physical ทั้งหมด — กรอง MediaType -eq 'SSD' และ BusType -ne 'USB' (USB bridge รายงานอุณหภูมิมั่ว)
Get-StorageReliabilityCounterดึง SMART: Temperature / Wear — ต้อง admin จึงจะคืนค่าได้
TProcessspawn powershell.exe -NoProfile -NonInteractive -Command … แบบ hidden (poNoConsole) แล้วอ่าน stdout ผ่าน poUsePipes
Shell_NotifyIcon(NIM_ADD/MODIFY/DELETE)สร้าง/อัปเดต/ลบ ไอคอนใน system tray — ส่ง struct TNotifyIconDataA ที่ระบุหน้าต่างรับ callback
HWND_MESSAGE window"message-only window" — หน้าต่างมองไม่เห็นทำหน้าที่รับ event ของ tray + timer ทำให้ทั้งแอปเป็น single-thread event-driven ไม่มี lock เลย
SetTimer(hwnd, 1, 5000, nil)ตั้งนาฬิกาให้ Windows ยิง WM_TIMER ทุก 5 วิ → ทริกเกอร์การอ่านอุณหภูมิรอบใหม่ (ไม่ใช่ thread นอนหลับ)
CreateFontW + DrawTextWวาดตัวเลขอุณหภูมิตัวหนากลางไอคอน 32×32 (ตัวเลข 3 หลักย่อฟอนต์อัตโนมัติ) — GDI ล้วน ไม่ง้อระบบ UI ใด
CreateIconIndirectเอา bitmap สี + mask ที่วาดไว้ แปลงเป็น HICON จริงเพื่อป้อนเข้า tray
TrackPopupMenuEx(TPM_RETURNCMD)เปิดเมนูคลิกขวาแล้ว "รอ" คำตอบเป็นตัวเลข id ของเมนูที่ผู้ใช้เลือก (1=Details, 2=Refresh, 3=Exit)
CreateMutexW + GetLastErrorกันเปิดซ้ำ: ถ้ามี instance อื่นถือ mutex ชื่อเดียวกันอยู่ → ERROR_ALREADY_EXISTS → ออกทันที
GetMessage / DispatchMessagemessage pump คลาสสิกของ Win32: กระจาย WM_TIMER/WMBUTTON ที่เราจับใน LiteWndProc จนกว่า Exit จะโพสต์ WM_QUIT
