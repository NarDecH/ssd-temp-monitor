v1.2.0 21 กันยายน 2026

🔬 ผลวิจัยเพิ่มเติม: วัดจริงพบว่า bridge chip USB (ASM236X) ทำให้การอ่าน reliability counter ค้าง 42 วินาที (NVMe ปกติ 0.1 วินาที) — ไม่ใช่แค่รายงานค่าผิด แต่ทำให้ query ที่อ่าน counter ทุกดิสก์ชน timeout เสมอ วิธีแก้: กรอง USB ให้เสร็จก่อนอ่าน counter (query เหลือ ~1 วินาที)

Fixed

  • Polling ค้าง/timeout เมื่อเสียบ USB reader — แยกเป็น 2 query: อ่านอุณหภูมิเฉพาะดิสก์ภายใน (เร็ว) ส่วน debug list ไม่อ่าน counter ของ USB เลย

Added

  • เมนู Show all disks (debug) — ทุกดิสก์พร้อม MediaType / BusType และเครื่องหมาย ✓/✗ ว่าถูกนับหรือถูกกรอง
  • เมนู Record history + Show temperature graph — กราฟ 30 นาที (min/max/avg) เก็บลง CSV ใน %TEMP% (auto-flush ทุก 60 s)
  • ssd_temp_monitor.exe สำเร็จรูป (PyInstaller) — ผู้ใช้ไม่ต้องติดตั้ง Python พร้อม build_exe.bat, make_icon.py, app_icon.ico สำหรับ rebuild

Changed

  • Self-elevate (UAC) รองรับทั้งสคริปต์ .py และ exe
  • ไอคอน tray มี cache ลดการวาดซ้ำทุกวินาที

v1.1.0 21 กันยายน 2026

🎯 แก้บั๊กหลัก: เมื่อเสียบ USB card reader เครื่องจะอ่านอุณหภูมิ SSD ผิดพลาด — ตอนนี้โปรแกรมแสดงเฉพาะ SSD ภายในเครื่องเท่านั้น (USB reader ที่ Windows รายงานเป็น SSD ถูกกรองด้วย BusType -ne 'USB')

Fixed

  • กรองดิสก์ที่ต่อผ่าน BusType USB ออกจากการอ่านอุณหภูมิ — USB card reader / enclosure หลายรุ่นถูกรายงานเป็น MediaType = 'SSD' แต่ bridge chip ให้ค่า temp ที่ผิด (ค่าว่าง, 0, 65535)
  • แก้บั๊กแฝง: ค่า temp เป็นสตริงว่างทำ int("") ยก ValueError และเธรดอัปเดตล่มเงียบ ๆ (ไอคอนค้างค่าเดิม) — แปลงค่าแบบปลอดภัยแล้ว
  • Sanity check อุณหภูมิต้องอยู่ช่วง -20..100 °C — ค่านอกช่วงแสดง n/a

Changed

  • start_ssd_temp_monitor.bat ใช้ %~dp0 แทน path ตายตัว C:\_Project\ssd_temp_monitor\ — ย้ายโฟลเดอร์ได้อย่างอิสระ

Added

  • เอกสารใน docs/: คู่มือผู้ใช้ไทย, research, changelog (.md + .html พร้อมรูปแผนภาพ SVG)
  • AGENT.md — คู่มือสำหรับ AI coding agent
