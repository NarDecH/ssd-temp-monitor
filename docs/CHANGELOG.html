v1.23.0 24 กันยายน 2026

Fixed

  • 🛑 กด Settings แล้วโปรแกรมปิดตัว — crash native ใน tcl86t.dll (0x80000003) จาก Tcl interpreter สองตัวถูกใช้ข้ามเธรดเมื่อเปิดหน้าต่างสองบานพร้อมกัน + tk_after ยังเรียก event_generate ข้ามเธรด — marshaler ใหม่ไม่แตะ Tcl จากเธรดอื่นเลย (queue + drain loop บนเธรด tk) และมี watchdog รี-รัน tray loop ถ้าถูก crash ปิดทิ้ง (log tray_loop_restarted)
  • 📴 About ค้าง "checking…" — callback หายพร้อม crash + ไม่มี retry เมื่อเน็ตล่ม — worker retry ถึง deadline 20 วิ แล้วขึ้น offline ให้เสมอ (คีย์ about.latest.retrying ครบ 4 ภาษา) เช็คหน้าต่างด้วย flag แทน winfo_exists ข้ามเธรด
  • 🎨 About อ่านไม่ออกบนธีมสว่าง — สีเคย hardcode สำหรับธีมมืด — ใช้พาเลตต์ทั้งหน้า (มีสี link ใหม่) และไฮไลต์ผลเช็คเวอร์ชัน: มีเวอร์ชันใหม่ = ส้มหนา, ตรง = เขียว, offline = muted

Changed

  • 📝 Rotating log เปิดไฟล์แบบ lazy — startup ไม่ติดถ้า log ถูกล็อก · quit ให้เวลาหน้าต่าง tk ปิดตัว 0.3 วิ ลด Tcl panic ตอนปิดโปรแกรม
