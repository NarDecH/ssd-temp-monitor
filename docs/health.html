วิธีอ่านหน้านี้

  • Release CI checks = ผล workflow ของ tag ล่าสุด (build + test + sign + checksum) — ถ้าเป็น success แปลว่าไฟล์ที่ปล่อยผ่านทุกขั้น

  • ทุกตัวเลขดึงสดผ่าน api.github.com (public, unauthenticated) — ถ้า GitHub จำกัดอัตรา หน้าจะขึ้นสถานะ "rate limited" แล้วลองใหม่เอง
